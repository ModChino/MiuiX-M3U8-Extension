# MiuiX M3U8 浏览器扩展（Manifest V3）

嗅探网页里的 **m3u8 / mpd**，手动选一条后**连同请求头**（Referer / Cookie / User-Agent / 自定义头）
交给本地 MiuiX M3U8 建下载任务（后端是 N_m3u8DL-RE）；也可以**一键复制 N_m3u8DL-RE 命令行**，不经过 GUI。

> 不上架商店，用开发者模式加载。界面按 Miuix / HyperOS 设计规范
> （`docs/MIUIX_TOKENS.md`）实现，外观三选一：跟随系统 / 浅色 / 深色。

## 功能

| 能力 | 说明 |
|---|---|
| 嗅探 | `webRequest` 观察所有请求：URL 命中 `.m3u8` / `.mpd`，或响应 `Content-Type` 是 HLS/DASH |
| 候选列表 | 落 `chrome.storage.session`（Service Worker 被挂起也不丢），只在**主文档跳转**时清空 |
| 清晰度 | 先解析清单正文（`#EXT-X-STREAM-INF` / `<Representation>`），失败再用 URL 线索（`1080p`、`/1080/`、`4k`、`bandwidth=`）；都没有就显示「未知」 |
| 默认选中 | **永远预选最高画质**；全都没有画质信息时选最后捕获的那条（主播放列表通常在后面） |
| 手动发送 | 捕获后**不会**自动提交 —— 预加载、广告位的 m3u8 只会躺在列表里 |
| 复制命令 | 生成 `N_m3u8DL-RE "url" --save-name "标题" -H "Referer: …" … --auto-select`，引号与反斜杠按 .NET 命令行规则转义 |
| 两种界面 | 「点扩展图标弹面板」和「页面右下角常驻悬浮窗」，在扩展设置里切换 |
| 外观 | 跟随系统 / 浅色 / 深色三选一，改完**立即生效**（不用刷新页面），弹出面板、设置页、页面悬浮窗三处同时跟随 |
| 标题 | 取 `chrome.tabs` 的页面标题，去掉 B 站 / YouTube 等站点后缀与 Windows 非法文件名字符 |

## 目录结构

    MiuiX-M3U8-Extension/
    ├── manifest.json          MV3 清单（permissions: webRequest / storage / tabs / scripting）
    ├── background.js          Service Worker：webRequest 监听、候选管理、POST /add
    ├── lib/logic.js           纯逻辑（清晰度 / 去重 / 标题 / 命令行 / 请求头），不含任何扩展 API
    ├── lib/ui.js              popup 与悬浮窗共用的 DOM 片段
    ├── content.js             页面悬浮窗（可开关，Shadow DOM 隔离样式）
    ├── content.css            悬浮窗样式
    ├── popup.html/js/css      点扩展图标弹出的候选面板
    ├── options.html/js/css    端口 / 令牌 / 界面形式 / 外观 / 默认行为
    ├── common.css             Miuix 设计 token（CSS 变量）与公共组件
    └── icons/                 16 / 32 / 48 / 128 PNG + gen-icons.mjs（node 生成，无依赖）

## 安装（开发者模式）

1. Chrome / Edge 打开 `chrome://extensions`（Edge 是 `edge://extensions`）。
2. 打开右上角 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择本目录 `MiuiX-M3U8-Extension`
   （也可以在 MiuiX M3U8 的「设置 → 浏览器扩展 → 打开扩展目录」里直接打开这个文件夹）。
4. 加载成功后工具栏出现蓝色下载图标，点它就能看到候选面板。

> **Chrome 重启后会弹「停用开发者模式扩展」**：一定要点 **保留**（Keep）。
> 如果不小心点了「停用」，扩展会变灰，回到 `chrome://extensions` 重新启用即可。
> 这是所有未上架扩展都会遇到的提示，不是扩展本身的问题。

## 配置端口和令牌

本地接收端默认是**关闭**的，必须先在 MiuiX M3U8 里打开：

1. 打开 MiuiX M3U8 → 左侧 **设置** → **浏览器扩展** 卡片。
2. 打开 **接收端** 开关（打开后卡片里就会出现端口和令牌）。
3. 记下 **端口**（五位数，如 `18923`），点 **访问令牌** 右侧的复制按钮。
4. 回到浏览器：点扩展图标 → **设置**（或在 `chrome://extensions` 里点「扩展程序选项」）：
   - 端口和令牌填进去 → 点 **测试连接**，应显示「已连接 MiuiX M3U8 · 端口 xxxxx」。
   - 「界面形式」选 **点图标弹面板** 或 **页面悬浮窗**。
   - 「外观」选 **跟随系统 / 浅色 / 深色**（只影响扩展自己的界面，不动网页本身）。

> 端口或令牌变了（在 MiuiX M3U8 里点了「随机」换端口 / 重置令牌），扩展这边要同步改一次。
> MiuiX M3U8 状态行显示的是接收端**真实**在跑的地址：`http://127.0.0.1:<port>`。

## 使用

1. 在视频网站把视频**播起来**（播放器开始拉清单才会被嗅探到）。
2. 点扩展图标（或页面右下角悬浮球）：列表按清晰度从高到低排列，**默认已选中最高画质**。
3. 选一条，然后二选一：
   - **发送到 MiuiX M3U8**：任务出现在 MiuiX M3U8「任务」页，文件名取网页标题（已清洗）。
   - **复制命令**：拿到一条完整命令行，粘到 cmd / PowerShell 里直接跑
     （需要 `N_m3u8DL-RE` 在 PATH 里，或把开头的 `N_m3u8DL-RE` 换成完整路径）。

## 安全说明

- 本地接收端只监听 **127.0.0.1**，且 **token 必填**（服务端用常数时间比较，见 `app/core/server.py`），
  网页脚本没法冒充扩展往下载器塞任务或探测内网。
- 扩展**不会**把任何数据发到网上：请求目标只有 `http://127.0.0.1:<端口>`，而且只在你点「发送」时才发。
- 扩展需要 `webRequest` + `<all_urls>` 才能看到请求头里的 Cookie / Referer，
  这是「带防盗链下载」的必需品；这些头只用于两处：发给本地 MiuiX M3U8、拼进你复制的命令行。
  如果 Chrome 因为敏感头策略没给扩展 Cookie，会退回读页面的 `document.cookie` 补齐（只填空缺，不覆盖已抓到的）。
- **复制出来的命令行里含 Cookie**，别直接贴到公开场合。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 面板一直「未连接本地接收端」 | 接收端没开 / 端口填错 / MiuiX M3U8 没启动。去「设置 → 浏览器扩展」核对 |
| 发送提示「访问令牌不对」 | 在 MiuiX M3U8 里重置过令牌，回扩展设置重新粘贴 |
| 候选列表是空的 | ① 视频还没开始播放；② 页面不是 http(s)（`chrome://`、扩展页、`file://` 都嗅探不到）；③ 纯 DRM 加密流；④ 视频在跨域 iframe 里（本扩展只收顶层标签页的请求） |
| 列表里有广告 / 预览的流 | 正常，扩展**不会**自动下载；刷新页面即可清空 |
| 复制的命令报「找不到命令」 | `N_m3u8DL-RE` 不在 PATH；把命令开头的可执行名换成完整路径，如 `"D:\MiuiX-M3U8\tools\N_m3u8DL-RE.exe"` |
| 发送成功但任务很快失败 | 用测试页的假地址时失败是预期的；真实站点失败多半是 Cookie 过期，重新播放一次再发 |
| 悬浮球挡住页面按钮 | 扩展设置里把「界面形式」改成「点图标弹面板」即可；悬浮球也可以**拖动**到别处（位置会记住），松手时靠近屏幕左右边缘会**自动吸附**贴边 |

## 在真实浏览器里验证

扩展装好后，在任意视频网站把视频**播起来**，点扩展图标：列表里出现候选、角标出现数字，
就说明嗅探在工作。候选是空的，按上面的「常见问题」逐条排查。
